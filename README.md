# doTime

基于 **Tauri 2 + React 19 + TypeScript** 的本地桌面待办与计时应用。支持按日期管理任务、多个任务同时计时、倒计时、提醒弹窗、迷你置顶模式和本地耗时统计。

## 功能

- **每日待办**：按日期查看任务，并支持手动拖拽排序
- **日期管理**：自绘月历标记有待办和已完成日期，编辑待办时可移动到其他日期
- **紧急程度**：低 / 中 / 高 / 紧急
- **多任务计时**：多个待办可以同时开始、暂停或结束计时
- **耗时统计**：按周或按月查看完成率、每日趋势和任务耗时排行
- **全局搜索**：跨日期搜索待办，并按状态、紧急程度和日期范围筛选
- **任务模板**：保存常用任务设置，快速套用并支持模板排序和管理
- **重复任务**：支持每天、工作日、每周指定星期、每月指定日期和结束日期
- **倒计时**：使用圆形拨盘或快捷预设设置计划时长
- **完成与恢复**：完成任务时结算当前计时；取消完成时，开启时间记录且已有耗时的任务会继续计时
- **定时提醒**：自定义提醒时间，支持批量关闭和 5 / 10 / 30 / 60 分钟后提醒
- **迷你模式**：窗口置顶、透明度调节、顶部自动收起
- **系统托盘**：关闭主窗口后保留后台提醒，可从托盘恢复或退出
- **主题切换**：暗色和亮色主题
- **数据管理**：可导出当前所选日期或全部日期的 TXT 待办文档，并在本地滚动保留最近 3 份有效快照

## v0.2 数据说明

doTime 不依赖 MySQL、PostgreSQL、SQLite 等数据库，也不需要安装额外的数据服务。

- 主数据使用版本化的浏览器 `localStorage` 文档保存
- 首次运行 v0.2 时会自动迁移旧版 `dotime-todos-v1` 数据
- 主数据损坏时会尝试从最近 3 份有效快照恢复
- 提醒窗口只发送提醒操作，由主窗口统一更新待办，避免多个窗口同时覆盖整份数据
- “导出当日”跟随当前选中的日期；“导出全部”包含所有日期
- 导出文件为 UTF-8 TXT 文档，按日期分组并为每个待办保留清晰间隔
- “导入旧备份”继续兼容 v0.2 之前已经导出的 JSON 文件

应用数据仍然只保存在当前电脑和当前系统用户目录中。TXT 文档适合阅读和归档，但不能直接恢复应用状态；卸载应用、清理 WebView 数据或重装系统时，本地自动快照也会一并删除。

## v0.3 日期管理

- 点击标题栏当前日期可打开自绘月历
- 黄色日期表示仍有未完成待办，绿色日期表示该日待办已全部完成，右上角显示数量
- 前一天、后一天和“今天”快捷操作继续保留
- 新建待办默认使用当前页面日期
- 编辑待办可修改任务日期；保存后自动跳转到目标日期
- 移动日期后会重新计算列表顺序，并重置旧日期的提醒触发状态

## v0.4 重复任务

- 完成当前项时只生成下一项，不会一次性创建大量未来任务
- 支持每天、工作日、每周多选星期、每月指定日期
- 每月日期在较短月份自动落到当月最后一天
- 可设置重复结束日期
- 编辑系列任务时可选择“仅本次”或“本次及后续”
- “仅本次”的内容修改不会影响下一项；“本次及后续”会更新系列模板

## v0.5 耗时统计

- 从标题栏图表按钮进入统计中心，再次点击可返回待办列表
- 支持按周和按自然月统计任务数、完成数、完成率与累计耗时
- 每日趋势同时显示耗时与完成任务数
- 耗时排行展示统计周期内用时最多的 5 个任务
- 点击趋势日期或排行任务可跳转到对应日期的待办列表
- 统计直接读取现有本地待办数据，不引入数据库或外部图表服务

## v0.6 全局搜索

- 标题栏搜索覆盖全部日期，不再局限于当前待办列表
- 支持按待办、已完成、计时中状态筛选
- 支持按低、中、高、紧急程度筛选
- 支持使用自绘日期选择器限制起始日期和结束日期
- 搜索结果显示日期、状态、紧急程度和累计耗时
- 点击搜索结果可跳转到对应日期并高亮目标任务
- 搜索与筛选直接基于现有本地数据，不修改存储格式

## v0.7 任务模板

- 新建待办时可从模板下拉框快速套用常用设置
- 模板保存标题、紧急程度、倒计时、提醒和时间记录设置
- 可选择是否保存重复规则，固定结束日期不会写入模板
- 应用模板时保留当前选择的任务日期
- 支持模板重命名、删除和手动上下排序
- 模板使用独立的版本化本地文档并保留一份有效备份
- 待办 TXT 导出和旧数据导入不会混入模板数据

## 使用提示

1. 点击标题栏的加号新建待办
2. 按需开启倒计时、提醒和时间记录
3. 点击“开始计时”，不同待办可以同时计时
4. 点击“结束计时”会停止计时、记录实际耗时并标记完成
5. 点击已完成任务可取消完成；符合续计时条件时会从已有耗时继续
6. 使用标题栏的数据管理按钮导出 TXT 文档，或导入旧版 JSON 备份

# doTime

基于 **Tauri 2 + React + TypeScript** 的桌面待办应用：按日记录任务、设置紧急程度、拖拽设置倒计时，并通过开始/结束计时统计完成耗时。

## 功能

- **每日待办**：按日期查看 / 切换，默认显示今天
- **紧急程度**：低 / 中 / 高 / 紧急，列表按紧急度排序
- **拖拽倒计时**：圆形拨盘拖拽设置计划时长（也可点快捷预设）
- **开始计时**：启动倒计时与用时累计（同时仅一项在计时）
- **结束计时**：停止计时、标记完成，并记录实际完成耗时
- **本地持久化**：数据保存在浏览器 `localStorage`

## 开发

```bash
cd doTime
npm install
npm run tauri dev
```

仅前端（浏览器预览）：

```bash
npm run dev
```

## 构建

```bash
npm run tauri build
```

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Tauri 2 |
| 前端 | React 19 + TypeScript + Vite |
| 状态 | React Hooks + localStorage |

## 使用提示

1. 点击「新建待办」，填写内容并选择紧急程度  
2. 拖拽圆环设置计划倒计时（或点 5 分 / 25 分等预设）  
3. 对某条待办点「开始计时」  
4. 完成后点「结束计时」——应用会自动统计本次耗时并标记完成

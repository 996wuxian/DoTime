# doTime

doTime 是一款基于 **Tauri 2 + React 19 + TypeScript** 的本地桌面待办与计时应用。它把每日待办、倒计时、耗时统计、计划视图、日复盘、搜索、收藏、模板和本地数据导出放在一个轻量窗口里，适合需要持续跟踪工作节奏的人。

## 每日待办与倒计时

![每日待办与倒计时](docs/images/01-daily-todos.png)

按日期管理任务，支持紧急程度、任务时间、倒计时、提醒、评论、收藏、子待办和拖拽排序。多个待办可以同时计时，完成任务时会结算实际耗时。

## 耗时统计与待办热力图

![耗时统计与待办热力图](docs/images/02-statistics.png)

按周或按月查看任务数、完成率、累计耗时、每日趋势和耗时排行。年度热力图从 1 月开始展示全年待办密度，方便快速回看长期投入分布。

## 周计划与月计划

![周计划与月计划](docs/images/03-plan-overview.png)

计划视图把待办按周或自然月铺开，直接展示每天的待办数量、完成情况和关键任务。点击日期可以跳回对应日期的待办列表。

## 日复盘

![日复盘](docs/images/04-daily-review.png)

日复盘会汇总当天的完成率、累计耗时、进行中任务、未完成任务、耗时最多任务、异常关注项和评论记录，适合收工前快速整理一天的执行情况。

## 待办提醒

![待办提醒](docs/images/07-reminder.png)

每个待办都能单独设置提醒时间，支持编辑时快速开启提醒、选择时分并在到点后弹出提醒窗口。

## 全局搜索

![全局搜索](docs/images/05-global-search.png)

跨日期搜索待办，支持按状态、紧急程度和日期范围筛选。点击搜索结果可以跳转到对应日期并高亮目标待办。

## 顶部迷你模式

![顶部迷你模式](docs/images/06-mini-mode.png)

把当前未完成待办收进窗口顶部，始终显示任务标题、进度、计时和操作按钮，适合专注执行时快速查看当前任务。

## 功能亮点

- 单实例运行：重复打开应用时唤起已有主窗口，支持从最小化或托盘隐藏状态恢复
- 每日待办：按日期组织任务，支持手动拖拽排序
- 快捷新建：在列表顶部输入标题后按 Enter 添加，自动清空并保留输入焦点；需要完整设置时可点击顶部新建待办，继续编辑同一份草稿
- 精简表单：提醒、备注、子待办、重复与图片收进“更多设置”，保存操作位于表单底部，支持保存并继续添加
- 倒计时与计时：支持计划时长、实际耗时、多个任务同时计时
- 子待办：支持两级子待办，适合拆解复杂任务
- 评论与收藏：为任务保留复盘备注，收藏重点待办并快速跳转
- 批量操作：批量完成、移动日期、删除、取消收藏
- 任务模板：保存常用任务设置，快速创建重复工作项
- 重复任务：支持每天、工作日、每周指定星期、每月指定日期
- 定时提醒：支持自定义提醒时间和稍后提醒
- 版本更新：在设置中检查 GitHub 正式版本，下载适合当前系统的安装包；无法下载时可打开发布页手动下载
- 迷你模式：窗口置顶、透明度调节、顶部自动收起；取消固定后再次固定时恢复之前的不透明度
- 草稿保留：新建、编辑与子待办表单自动保存草稿，切换页面或重启后可继续，支持明确放弃草稿
- 数据管理：导出含待办、子待办、模板、排序和图片的可恢复 JSON 备份，也可导出当前日期或全部日期的 TXT 阅读文档
- 本地优先：主数据保存在本机 localStorage，不依赖远程服务

## 数据说明

doTime 不依赖 MySQL、PostgreSQL、SQLite 等数据库，也不需要安装额外的数据服务。

- 主数据使用版本化的浏览器 `localStorage` 文档保存
- 主数据损坏时会尝试从最近 3 份有效快照恢复
- 提醒窗口只发送提醒操作，由主窗口统一更新待办
- “导出当日”跟随当前选中的日期；“导出全部”包含所有日期
- “导出可恢复备份”生成独立的 JSON 文件，图片内容内嵌，可在另一台电脑恢复；不包含草稿、外观设置与剪贴板历史
- “从备份恢复”先展示待办、图片、模板数量及日期范围，经确认后覆盖待办与模板；兼容旧版 JSON 待办备份
- 恢复前会保留一份含图片的原数据，可通过“恢复上次导入前的数据”找回；恢复失败时自动尝试回退
- 进行中的计时以导出时的进度保存，恢复时继续，不累计备份存放期间的时间
- TXT 文档使用 UTF-8，适合阅读和归档，不能用于恢复
- 未提交的表单与图片草稿使用本机 IndexedDB 保存，成功提交后清除对应草稿
- 应用数据只保存在当前电脑和当前系统用户目录中

## 开发

```bash
npm install
npm run tauri:dev
```

仓库中的 Cargo 配置使用官方 crates.io sparse 源，供 CI 和发布构建使用。本地如需镜像、代理或其他网络设置，请放在 `$CARGO_HOME/config.toml`（未设置 `CARGO_HOME` 时为 `~/.cargo/config.toml`），不要把本机网络配置提交到仓库。

仅运行浏览器预览：

```bash
npm run dev
```

## 验证

```bash
npm test
npm run build

cd src-tauri
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
```
